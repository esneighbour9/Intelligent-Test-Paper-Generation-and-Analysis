# 开发环境搭建指南

> 目标：把 Windows 上的开发环境配好，让后端（Spring Boot）和前端（Vue）都能跑起来。
> 不确定装了没关系 —— 先照第 1 节检查，缺什么补什么。
> 版本：v1.0　更新日期：2026-10-05

---

## 1. 先检查：你已经装了什么

打开「命令提示符」（开始菜单搜 `cmd`）或「PowerShell」，逐条运行下面的命令，**把输出记下来发给 Claude**：

| 命令 | 检查的是 | 期望看到的 |
|---|---|---|
| `java -version` | JDK 是否安装 | 版本号，如 `openjdk version "17.0.11"` |
| `javac -version` | JDK 编译器 | 版本号 |
| `mvn -v` | Maven 是否安装 | 版本号与 Java 版本 |
| `mysql --version` | MySQL 是否安装 | 版本号，如 `8.0.x` |
| `node -v` | Node.js 是否安装 | 版本号，如 `v18.x` |
| `npm -v` | npm 是否安装 | 版本号 |
| `git --version` | Git 是否安装 | 版本号（你应该已经有） |

**怎么看结果：** 如果命令正常输出版本号，说明装好了；如果提示「'xxx' 不是内部或外部命令」，说明**没装或者没配到 PATH**。

把这张表的输出发我，我就能判断你要补装什么。

> 小提醒：如果 `java -version` 显示的是 `1.8.0` 之类的，说明装的是 JDK 8 —— 也能用，但后端会用 Spring Boot 2.7.x（写法略有不同）。所以先确认这个。

## 3. 逐个安装要点

### 3.1 JDK 17
1. 打开 https://adoptium.net/ ，下载 **Temurin 17 (LTS) 的 Windows .msi**。
2. 安装时**勾选** `Set JAVA_HOME variable` 和 `Add to PATH`（这两个勾选能省掉手动配环境变量）。
3. 重新打开一个命令行窗口，运行 `java -version` 验证。

### 3.2 Maven
1. 下载 **Binary zip archive**，解压到比如 `C:\dev\apache-maven-3.9.9`（路径不要有中文和空格）。
2. 配环境变量：
   - 新建系统变量 `MAVEN_HOME` = `C:\dev\apache-maven-3.9.9`
   - 编辑 `Path`，新增一项 `%MAVEN_HOME%\bin`
3. 重开命令行，运行 `mvn -v` 验证。
4. **接着做第 4 节的镜像配置**（很重要，否则下依赖会很慢）。

### 3.3 MySQL 8.0
1. 从 https://dev.mysql.com/downloads/ 下载 **MySQL Community Server**（Windows MSI Installer）。
2. 安装类型选 `Developer Default` 或 `Server only`。
3. 到设置密码那一步：**给 root 用户设一个密码并记牢**（后面连数据库要用）。为了本地开发方便，密码设简单点没关系（例如 `123456`），但**不要用这个密码上线**。
4. 安装完成后验证：`mysql --version`；能进 `mysql -u root -p` 输入密码后进入 `mysql>` 提示符即成功。

### 3.4 IntelliJ IDEA Community
1. 下载 Community 版（免费），一路默认安装。
2. 装完打开，先不用建项目，后面我用它带你打开生成的工程。

### 3.5 Node.js 18 LTS
1. 下载 LTS 的 Windows Installer (.msi)，一路默认（会自动配置 PATH）。
2. 重开命令行，运行 `node -v` 和 `npm -v` 验证。

## 4. Maven 国内镜像配置（强烈建议）

Maven 默认从国外服务器下载依赖，国内会很慢甚至卡死。配置阿里云镜像可显著加速。

**做法**：在用户目录下新建 `.m2` 文件夹（通常是 `C:\Users\你的用户名\.m2\`），在里面新建文件 `settings.xml`，内容如下：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<settings xmlns="http://maven.apache.org/SETTINGS/1.0.0">
  <mirrors>
    <mirror>
      <id>aliyunmaven</id>
      <mirrorOf>*</mirrorOf>
      <name>阿里云公共仓库</name>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
</settings>
```

> 如果你在 Maven 安装目录的 `conf/settings.xml` 里本来就有配置，也可以把上面 `<mirror>` 那段加到它的 `<mirrors>` 标签里。
