## 命名约定

- 文档：`序号-中文名.md`，如 `03-需求规格说明书.md`
- 图片：统一放入所属目录的 `images/` 子目录（论文图片统一放 `07-论文/images/`）
- 每份文档头部标注版本与更新日期

## 维护说明

设计先行、实现对照设计；设计变更时同步更新文档并提交（提交类型 `docs:`）。避免"文档与实现脱节"。
